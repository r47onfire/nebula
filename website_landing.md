---
title: Nebula
---

Nebula is a grammar-driven packrat parser engine with left-recursion
support. Grammars are just plain JSON; parsing produces a concrete
syntax tree whose leaves reproduce the input exactly, and syntax errors come
back as nodes in the tree instead of exceptions.

Start with the guides in the sidebar, or browse the API reference for the
combinators, `parseToCST`, and the CST utilities.
